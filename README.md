# 해부학 단답 자동채점 (프로토타입)

「해부학 서면평가 자동채점 프로그램 개발 기획서」를 바탕으로 만든 동작형 웹 프로토타입입니다.
학생 30명의 **모의 데이터**로 동작하며, 실제 스캔·판독 엔진과는 연결되어 있지 않습니다.

## 화면
현황 · 문항은행 · 시험지/정답지 · 스캔·판독 · 검토 · 성적·분석 · 파일럿 비교 · 사용설명서

## 실행
`index.html` 하나로 동작합니다. 브라우저로 열거나 아래 방법으로 배포하세요.

- **GitHub Pages**: Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save
- **Vercel**: 이 폴더에서 `npx vercel deploy --prod`

## 주의
- 판정·이력은 보는 사람의 브라우저(localStorage)에만 저장됩니다.
- 실제 학생 정보를 넣기 전에 접근 제한과 승인된 저장소가 필요합니다.
